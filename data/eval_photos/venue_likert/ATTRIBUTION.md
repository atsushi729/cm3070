# venue_likert photo set — attribution

18 restaurant/café/food photos, resized to a 1600px long edge (JPEG q85),
collected from Wikimedia Commons for the UC2-C suggestion-quality Likert
evaluation (自システム vs GPT-4 vs generic tips). All CC BY / CC BY-SA /
public-domain; attribution below satisfies the license terms for
redistribution. Full metadata (raw popularity score used for stratified
selection, source title/URL) is in `manifest.json`.

Selection method: queried Wikimedia Commons categories (Food photography,
Cafés, Sushi, Ramen, Izakaya, Restaurants) via the Commons API, filtered to
JPEG/PNG ≥800px and excluded historical/archival photos and off-topic results
(airline meal, non-venue candid photo, a vintage postcard collage) found on
manual review, then scored the remaining 45 with the existing
`app.ai.popularity` + `app.services.attributes` pipeline and picked 18 evenly
spaced across the raw-score range (min -0.82 to max +6.50) for quality
diversity.
